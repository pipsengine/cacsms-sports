# CACSMS SPORTS v4.0 — Navigation and frontend responsibility refactor

## Scope
- 29 routes retained across 8 groups; existing route slugs preserved.
- Group order updated to Control Centre, Sports Intelligence, Market Intelligence, Betting Programmes, Ticket & Booking, Results & Learning, Engine Operations, Administration.
- League tables moved ahead of research; Engine Orchestrator is first in Engine Operations.
- Collapsible, accessible group controls and active group indication.
- Branding updated to CACSMS SPORTS in shell, breadcrumbs and footer.
- Per-page descriptions added; existing backend-driven workspaces retained.
- Dashboard and Command Centre no longer duplicate the full Engine Orchestrator.
- Source Intelligence no longer duplicates the Live Operations acquisition monitor.
- Research Coverage remains a separate research page without a redundant generic dataset.
- No live wagering added; PAPER mode retained.

## Not yet completed
Dedicated designs for all 29 pages, complete UI permission enforcement, responsive visual browser QA, frontend build and deployed end-to-end verification require further work. This release is a focused shell/navigation restructuring, not production certification.
