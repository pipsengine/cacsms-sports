# Version 2.9 — Monitoring and GitHub readiness

Added:
- Read-only, correction-aware per-model monitoring endpoint.
- Brier score, log loss, 10-bin calibration error, window comparison and degradation flags.
- Explicit minimum-sample states and no automatic model activation.
- GitHub CI, security audit, Dependabot and PR checklist.
- Private-repository setup guide.

Limits:
- Drift monitoring is descriptive and does not establish profitability or causality.
- Results acquisition still requires an authorized external provider and verified evidence.
- No deployment, live bookmaker integration, automated retraining, or production database validation has been performed.
- Real-money execution remains disabled.
